# A Simple Optimization Test Case for MMA

This example demonstrates a simple test case for the Method of Moving Asymptotes (MMA), using a scalar field defined over the GLL (Gauss–Lobatto–Legendre) points of a spectral element mesh.

The goal is to test the MMA implementation on a simple optimization problem where all the sensitivity information is computed analytically, without the need for FEM simulations.

For this example, we read a simple mesh file (`box.nmsh`)—typically a spectral element mesh for a box generated by the `genmeshbox` tool in NEKO.

## Problem Description

In the `driver.f90` file, the distribution of a scalar field in the mesh is defined as the design field (`de`) using the `simplefield_design_t` type.

> Note: The design variables are defined at every GLL point in the mesh.

The fields are managed through Neko’s internal `field_t` abstraction. Each GLL node has one design variable associated with it, so the total number of design variables equals the number of GLL points in the mesh.

The `simplefield_design_t` has four vectors:

```fortran
type(vector_t) :: values
type(vector_t) :: x
type(vector_t) :: y
type(vector_t) :: z
```

These represent the design variable value, and the x-, y-, and z-coordinates of its corresponding GLL point. All four vectors have a length equal to the total number of GLL points in the mesh.
For simplicity, in this file, we use `des%values` instead of `des%values%x`. (Please check the vector_t description in NEKO) 

---

## Objective Function

The objective is to **minimize the average value** of the design variables.


$$
J = \quad \frac{1}{n} \sum_{j=1}^{n} \texttt{des.values}(j)
$$

where:

- $\texttt{des.values}(j)$ is the value of the scalar field at the $j$-th GLL node,
- $n$ is the total number of GLL points in the mesh.


The sensitivity (gradient) of the objective with respect to each design variable is constant:
Let $[d_1, d_2, \ldots, d_n]$ denote the vector of design variables, we have:

$$
\frac{\partial J}{\partial d_j} = \frac{1}{n}
$$


## Constraints
Constraints are used here to enforce a given distribution for the scalar design field.
For this example we want the scalar design field to match the x-coordinate at every GLL point, i.e.,

$$
\texttt{des.values}(j) = \texttt{des.x}(j), \quad \forall j = 1, \ldots, n.
$$

Since MMA handles only inequality constraints, we impose this equality by defining the following inequality constraint based on the mean squared deviation:

$$
G = \frac{1}{n} \sum_{j=1}^{n} \left( \texttt{des.values}(j) - \texttt{des.x}(j) \right)^2 \leq 0
$$

The sensitivities are given by

$$
\frac{\partial G}{\partial d_j} = \frac{2}{n} \left( \texttt{des.values}(j) - \texttt{des.x}(j) \right),
$$

This formulation effectively enforces the equality by bounding the squared deviation.


---
## Interpretation

The full optimization problem can be stated as:

$$
\begin{aligned}
\min_{\mathbf{d}} \quad & J(\mathbf{d}) = \frac{1}{n} \sum_{j=1}^n d_j, \\
\text{subject to} \quad & G(\mathbf{d}) = \frac{1}{n} \sum_{j=1}^n (d_j - x_j)^2 \leq 0, \\
& d_j \in [\texttt{xmin}, \texttt{xmax}], \quad j=1,\ldots,n,
\end{aligned}
$$

where $\mathbf{d} = [d_1, d_2, \ldots, d_n]$ represents the design variables, and $x_j$ is the $x$-coordinate at the $j$-th GLL point.

The constraint $G$ effectively enforce the equality constraint $d_j = x_j$ by bounding the mean squared deviation to zero.

Since the objective minimizes the average of the design variables, and the constraints force the design field to match the \(x\)-coordinates, the expected optimal solution is:

$$
d_j = x_j, \quad \forall j=1,\ldots,n.
$$

For the default bounds `"xmin": 0.0` and `"xmax": 5.0`, if the mesh $x$-coordinates exceed these limits, the optimizer will cap the design variables accordingly.

## Files

- `example_problem.f90`: Contains custom definitions for the objective and constraint functions.
- `box.nmsh`: Mesh file defining the spectral element grid.
