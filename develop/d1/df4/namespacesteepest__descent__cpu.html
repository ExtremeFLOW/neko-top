Detailed Description

Elementwise kernels of the steepest descent method with move limits, Appendix D of da Silva, Aage, Beck & Sigmund (2021), Eqs. D22-D24. The device backends in bcknd/device implement the same formulas.

Computes x_new = min(xmax, max(xmin, min(x + delta, max(x - delta, x + psi * (s / smax))))), i.e. the move limit first and the box second. This equals Eq. D24 whenever x lies in [xmin, xmax], and stays well defined for infeasible x.

The move limit of a variable shrinks when its last two changes have opposite signs, grows when they have the same sign, and is then clamped to [dmin, dmax].
