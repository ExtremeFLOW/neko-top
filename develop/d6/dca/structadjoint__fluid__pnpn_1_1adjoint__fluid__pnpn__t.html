The adjoint equations are linear in the adjoint velocity, and the primal velocity convects it. The explicit convective terms therefore limit the time step through the primal velocity, the baseflow, and not through the adjoint velocity, whose amplitude scales with the objective. The baseflow is the final forward state in a steady problem, and the forward state restored for the current step in an unsteady one.

The CFL number of the baseflow.

◆ require_gauss_stack()

procedure, non_overridable, pass adjoint_fluid_scheme::adjoint_fluid_scheme_t::require_gauss_stack ( class(adjoint_fluid_scheme_t), intent(inout), target this)

Build the Gauss over-integration stack on first request.

Constructs Xh_GL, dm_Xh_GL, gs_Xh_GL, c_Xh_GL, GLL_to_GL and scratch_GL. The stack is only needed by consumers that over-integrate, so it is built on demand rather than in init_base. The routine is idempotent: a repeated call is a no-op, leaving any pointers already captured into the stack valid.

Note
dofmap_tinit, gs_tinit and coef_tinit are collective, so every call site must be reached by all ranks.
Must be called after init_base, which associates msh and initialises Xh; both are read here.
Parameters
thisThe adjoint fluid scheme owning the stack.
