Detailed Description

Elementwise kernels of the steepest descent method with move limits, Appendix D of da Silva, Aage, Beck & Sigmund (2021), Eqs. D22-D24. They implement the same formulas as steepest_descent_cpu.f90.

Device kernel for the move-limited, box-constrained update (D24). x_new = min(xmax, max(xmin, min(x + delta, max(x - delta, x + psi * (s / smax))))).

Device kernel for the move-limit adaptation (D23). With d = (x - x1) * (x1 - x2), delta is scaled by dec where d < 0, by inc where d > 0, left unchanged where d = 0, and then clamped to [dmin, dmax].

Parameters
deltaMove limits, updated in place.
xDesign variables at the current iteration.
x1Design variables one iteration back.
x2Design variables two iterations back.
decFactor applied on oscillation.
incFactor applied on monotone progress.
dminSmallest allowed move limit.
dmaxLargest allowed move limit.
nNumber of design variables.
